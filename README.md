## 🌟 O Projekcie

**Symulacja Giełdy** to edukacyjna platforma stworzona z myślą o osobach, które chcą poznać mechanizmy działania giełdy bez ryzykowania prawdziwych pieniędzy. Projekt umożliwia naukę inwestowania poprzez wirtualne **konto maklerskie**. 

Na start otrzymujesz wirtualne `10 000 PLN`, którymi możesz obracać na symulowanym rynku z prawdziwymi firmami technologicznymi i ETF-ami. Ceny akcji symulują prawdziwą dynamikę i ulegają losowym zmianom w czasie, co nadaje autentyczny i ekscytujący klimat giełdy.

## ✨ Główne Funkcjonalności

- 💼 **Konto Maklerskie:** Zarządzaj swoim budżetem i portfelem. Twój stan gry jest na bieżąco zapisywany w `Local Storage` przeglądarki.
- 📊 **Dynamiczny Rynek:** Akcje znanych firm (Apple, Tesla, Microsoft, CD Projekt) oraz ETF (S&P 500) z płynnymi aktualizacjami cen co kilka sekund.
- 🛒 **Kupno i Sprzedaż:** Interaktywne okno transakcyjne zabezpieczające przed zakupami, na które Cię nie stać, wraz z podglądem całkowitego kosztu.
- 🎨 **Premium UI/UX:** Atrakcyjny wizualnie, responsywny interfejs oparty o *Dark Mode* i stylizację *Glassmorphism* stworzony za pomocą czystego CSS.
- 📉 **Historia i Śledzenie Portfela:** Przejrzysty wykres oraz tabela podsumowująca Twoje zyski, straty i uśrednioną cenę wejścia.

## 🚀 Jak uruchomić projekt?

Postępuj zgodnie z poniższymi krokami, aby uruchomić aplikację lokalnie na własnym urządzeniu.

### 1. Wymagania wstępne
- **Node.js** zainstalowane w Twoim systemie operacyjnym.

### 2. Instalacja i uruchomienie

Sklonuj repozytorium na swój dysk:
```bash
git clone https://github.com/Swedrft/symulacja_gieldy.git
```

Przejdź do folderu projektu:
```bash
cd symulacja_gieldy
```

Zainstaluj wymagane pakiety:
```bash
npm install
```

Uruchom lokalny serwer deweloperski:
```bash
npm run dev
```

Platforma będzie dostępna w przeglądarce pod domyślnym adresem: `http://localhost:5173/`
